# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, welcome people of every background and experience level, and focus on what is best for the project. Harassment, insults and personal attacks are not tolerated.

## Reporting

To report unacceptable behaviour, contact the maintainer privately through GitHub ([@abrahamjoji](https://github.com/abrahamjoji)). Reports are handled confidentially. The maintainer may remove comments, commits or contributions that break this code, and may block repeat offenders from the project.
